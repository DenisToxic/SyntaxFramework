# SyntaxFramework

A modular FiveM framework for building structured and scalable roleplay servers.

## 🚀 Overview

SyntaxFramework is a custom-built framework for FiveM servers, designed to provide a clean and extensible foundation for roleplay systems.

It focuses on modularity, maintainability, and clear separation of concerns between core systems such as players, permissions, world logic, and UI.

The framework integrates backend logic (Lua), database persistence, and a modern UI layer.

---

## ✨ Features

* Modular system architecture
* Player management system
* Permission and role handling
* World and entity logic
* Integrated UI (Vue.js)
* Database support (SQL)

---

## 🧱 Architecture

The project is structured into independent modules:

* `syntax_core` – core framework logic
* `syntax_player` – player handling and state
* `syntax_permissions` – permission and access control system
* `syntax_world` – world and environment logic
* `syntax_ui` – frontend interface (Vue)
* `syntax_char` – character-related systems

This modular design allows systems to be extended or replaced without affecting the entire framework.

---

## 🛠️ Tech Stack

* Lua (server logic)
* JavaScript / Vue.js (UI)
* SQL (data persistence)
